# Blueprint OS 5.5 — Steve Intelligence

## Added
- Intelligent inbox scoring with a transparent 0–100 Steve score.
- “Why this matters” and suggested action on actionable emails.
- Inbox sorting prioritises higher-value messages first.
- “What should I do next?” recommendation on Today and Steve screens.
- Steve’s Daily Ops Brief now incorporates live Outlook signals.
- Draft Reply suggestions that remain fully under James’s control.
- Copy Draft + Open Outlook workflow; Blueprint does not auto-send replies.
- Existing 5.4.1 scrollable sidebar fix retained.

## Privacy and control
Steve Intelligence is rules-based in this release. It uses the data already available inside Blueprint OS and does not send personal data to an external AI service. Drafts are suggestions only and require review before sending.

## Setup
No new Supabase SQL, Microsoft permissions or Vercel environment variables are required if Version 5.4.1 is already working.
