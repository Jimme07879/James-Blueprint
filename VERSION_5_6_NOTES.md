# Blueprint OS 5.6 — Sales Command Centre

## Added
- Dedicated Sales navigation and command centre.
- Prospect/customer records with contact details, stage, follow-up date and next action.
- Potential weekly value and quote/opportunity value.
- Products/opportunity, current supplier and lead-source notes.
- Steve sales move: surfaces the next follow-up or highest-value active opportunity.
- Follow-ups due are added to the unified Today queue.
- Outlook matching when a sales record email address matches an inbox sender.
- One-click Contacted Today and Won actions.

## Database
Run `supabase/v5_6_sales_command.sql` once before using the new Sales fields. Existing sales lead records are preserved.
