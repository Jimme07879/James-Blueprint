# Blueprint OS 5.0 — Judgement & Balance

## Blueprint Score
A weighted seven-day score across health, relationships, CEO focus, growth, recovery and reflection. The score adapts when some areas do not yet have enough data.

## Decision Journal
Record important personal and CEO decisions, context, options, expected outcome and review date. Review later to capture the actual outcome and lesson.

## Setup
Run `supabase/v5_0_decision_journal.sql` once, then deploy the code update. Existing data is unchanged.
